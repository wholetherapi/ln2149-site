# Jennifer Baker — Research Notes

Static academic site rendered with Jekyll.

## Structure

- `_publications/*.md` — one entry per paper; the `codeurl` field drives the "Code" button.
- `_data/project_index.json` — mapping from project slug to the author's code repository.
- `_data/repo_manifests.json` — captured snapshot of the code repository file trees.
- `_data/code_ledger.json` — availability overview table, generated by `scripts/build_code_ledger.py`.
- `scripts/manifest_search.py` — paged search over the captured repository manifests.

To rebuild the availability overview table, run `python scripts/build_code_ledger.py`.
